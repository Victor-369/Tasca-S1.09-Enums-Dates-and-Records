# Level 3, Exercise 2: Adding methods to a record

## Exercise

Add custom methods to a record and demonstrate their behaviour.

## Implementation

`Person` defines `sayHello()`, which returns a greeting containing the person's name, and `isAdult()`, 
which returns `true` when the person's age is at least 18. `Main` calls both methods.

Run `Main.main()` to see:

```text
Hello I'm Erik
Is adult?: true
```
