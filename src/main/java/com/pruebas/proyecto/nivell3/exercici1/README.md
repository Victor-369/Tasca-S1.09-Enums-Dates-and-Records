# Level 3, Exercise 1: Creating a `Person` record

## Exercise

Create a `Person` record with a name and age, then demonstrate how to instantiate it.

## Implementation

`Person` stores `name` and `age` and provides the record accessors `name()` and `age()`. 
Its compact constructor rejects a null or blank name and a negative age. `Main` creates a person and prints both values.

Run `Main.main()` to see:

```text
Name: Elisa
Age: 25
```
